# Tools exposure study

Six HTML design documents explore whether and how to expose the personal site's Tools section.

## Recommendation

Use the **Homepage shelf** and **Article companion** together while there is one tool. Keep `/tools/` available as a canonical index and add a plain footer link, but do not add Tools to the primary navigation yet.

Promote Tools to primary navigation when one or more of these become true:

- the collection contains at least three distinct, maintained tools;
- tools cover at least two subjects and are no longer only companions to blog posts;
- analytics show meaningful repeat/direct traffic to tool pages;
- a visitor can reasonably browse the collection rather than choose the only item.

## Concepts

1. **Primary destination** — permanent nav item and dedicated directory.
2. **Homepage shelf** — a focused homepage interlude without a new nav item.
3. **Article companion** — contextual callout at the point of highest intent.
4. **Explore menu** — Blog and Tools grouped as authored output.
5. **Builds you can use** — utilities positioned as live portfolio projects.
6. **Quiet utility** — persistent low-profile drawer plus footer route.

Open `index.html` to compare all six directions.

Option 1 also includes `01-primary-destination-devices.html`, a dedicated phone, tablet, and desktop responsive study.
