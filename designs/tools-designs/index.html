Where should
Tools live?

A set of exposure strategies for a personal site that is simultaneously a résumé, a project portfolio, and a useful place to read. Each direction uses the existing rust, green, paper, and charcoal language.

Recommendation now

Use Concept 02 plus Concept 03. Put one compact “Useful things” shelf on the homepage and link the TFSA calculator directly from its related article. Keep the standalone /tools/ page and add a quiet footer link, but wait to give “Tools” a permanent primary-nav slot until there are roughly three distinct tools.

A simple promotion rule

Keep Tools contextual while the collection has 1–2 items. Promote it to the primary navigation when it has 3+ tools, when tools span 2+ subjects, or when analytics show repeat visits that are independent of the articles that introduced them.
